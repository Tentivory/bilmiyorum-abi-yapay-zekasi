# Bilmiyorum Abi Yapay Zekası

## Bu Ne Lan?

Bu, insanlık tarihinin en büyük icadıdır. Diğer yapay zekalar size yalan söyler, size her şeyi bildiklerini sanarlar. Biz öyle değiliz. Biz dürüstüz. Önce "Bilmiyorum abi" deriz, sonra da kafamıza göre bir şey uydururuz. Çünkü aslında kimse bir şey bilmiyor, sadece bazıları daha iyi uyduruyor.

### Nasıl Çalışır?

1. Soruyu sorarsın.
2. Yapay zeka derin bir nefes alır.
3. "Bilmiyorum abi..." der.
4. Sonra tamamen alakasız ama çok ciddi görünen bir cevap verir.

## Kullanım

```bash
python bilmiyorum_abi.py
```

Sonra sorunu yaz, Enter'a bas. Hayatın anlamını öğrenmeye hazır ol. Ya da olmayabilir.

## Özellikler

- %100 dürüst başlangıç
- %0 doğru cevap garantisi
- Sonsuz absürtlük
- Türkçe abi dili desteği

## Lisans

Bu kodu çalabilirsin ama "Bilmiyorum abi" demeyi unutma.
